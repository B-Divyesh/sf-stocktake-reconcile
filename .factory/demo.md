# Demo sandbox

Open `/demo` or use **Try it with sample data** on the landing page. It immediately loads three realistic inventory lines: brass hinges, roast coffee, and red canvas.

The demo worksheet is held only in memory for that browser page. It does not read or write the real worksheet or local storage. The persistent demo banner offers **Reset demo** to reload the sample and **Start for real** to discard it and open an empty workspace.
